## 使用与采集

在项目根目录执行 `python -B main.py --vision-web --vision-mode objects`。浏览器打开程序日志中的地址，先选择颜色并保持“允许发送”关闭。选择颜色本身不会打开串口。更换颜色、点击学习或修改识别参数会关闭发送并重置连续帧跟踪。

四种视图：原始画面（开启校正时为校正后的检测原图）、颜色分割、顶面边缘、识别结果。图中本色线表示整个物料外轮廓，紫十字为物料重心，黄椭圆/十字为通过验证的实测顶面，橙椭圆为未通过的假设，白圈 SEND 仅表示本帧成功调用发送接口的平滑目标。串口调用成功不等于下位机已经接收。

“保存原图与诊断包”下载同一帧 ZIP，包含未校正的 `camera-original.png`、用于算法复现的 `detection-original.png`、分割图、边缘图、诊断图、该帧状态和配置。PNG 是无损原分辨率，不是网页截图。高级参数可应用、保存到启动时使用的配置文件，或恢复识别默认值。恢复默认保留 HSV、ROI、相机等配置，需再点保存才落盘。

状态为：未发现物料、已找到物料但顶面未确认、顶面已确认但未稳定、可发送。“可发送”只表示识别具备条件，实际是否发送由独立开关和所选颜色决定。无效帧不会发送新坐标；这不等于主动停止下位机当前运动，通信协议没有改变。

## 算法与参数

保留 HSV、ROI、遮挡区、形态学去噪和连续帧跟踪。沿用每种颜色最大候选区域的选择规则；在该区域的原分辨率亮度/最大颜色通道边缘上拟合椭圆，以轴比、尺寸、面积比、贴合率、24 段圆弧覆盖和归一化圆形度验证。ROI/遮挡区边界、画面边缘截断均拒绝发送。跟踪与发送使用通过验证的顶面中心，物料重心单独保留。

`min_circularity` 不再被 0.62 截断：现在是对椭圆近邻边缘做轴向归一化后的凸包面积/外接圆面积，完整使用配置阈值。这与旧色块圆形度定义不同，需要用现场原图重新调参。旧的物料宽高比、extent/solidity 和 reference_point 偏移不再用于顶面筛选或发送；相关旧配置保留用于回退。没有足够边缘时宁可失败，不用物料重心冒充顶面中心。

## 离线与现场验证

解压采集包后执行（使用包内 config.json 可复现采集时的参数）：

```text
python -B -m logistics_robot.evaluate_top_face capture/detection-original.png --config capture/config.json --output evaluation
python -B -m unittest discover -s tests -q
```

离线工具输出 JSON（中心、失败原因、贴合率、覆盖率、轴比、耗时）与诊断 PNG，不连接相机或串口。静态图片只验证几何，不重复输入同一图片冒充连续稳定性验证。

采集红/黄/蓝/绿，每色覆盖近、中、远距离及正视、左右倾斜；另采同色背景、贴边出画和遮挡。为每张有效原图人工标记顶面中心，比较像素误差；失败样例应明确显示拒绝原因。现场连续预览记录中心抖动、实际帧率和消失后恢复需要的帧数，再决定容差是否可接受。

本地完整回归 106 项通过。测试覆盖 36 组合成颜色/尺寸/角度，中心误差 < 2 px，以及整片同色背景、ROI 截断、出画、遮挡、失效停发、原图无损下载、配置校验与发送默认关闭。合成通过不代表真实相机效果已验收。具有同样颜色和椭圆边缘的背景仍可能混淆，需要现场数据检查；当前没有高度/深度或物料语义模型。树莓派帧率、真实中心精度、短暂遮挡后的恢复和下位机接收仍待现场验证。
