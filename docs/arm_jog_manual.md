# 机械臂 5/6/7 号电机手动点动

此入口用于摄像头位置调试。5 号是旋转、6 号是前后、7 号是丝杆升降。
三轴与底盘 1～4 号同在 F4 的 Emm_V5 总线上；树莓派仍只连接 F4 的 UART3。
本次新增的指令需要把配套 F4 固件编译、烧录后才会生效。

目前正反方向未标定，没有限位开关。先让机械臂离开机械端点，清空运动范围，
现场有人观察并可切断电机电源。每次只执行一个电机的一个相对小步；F4 固定
5 rpm、加速度档 10，最多 32 个位置脉冲。不支持持续转动、自动回零或自动取放。

## 操作

在树莓派 `/home/pi/文档/pi`，先确认 Pi 源码已同步、F4 新固件已烧录，再执行：

```bash
python3 -B main.py --arm-status 7
python3 -B main.py --arm-jog 7 --arm-direction + --arm-pulses 8
python3 -B main.py --arm-jog 7 --arm-direction - --arm-pulses 8
python3 -B main.py --arm-stop 7
```

将 `7` 换成 `6` 或 `5`，逐个记录 `+` / `-` 的**实物运动方向**。
建议先用 8 脉冲；方向记录前不要连续重复。`--arm-jog` 在收到 F4 动作
结果后退出，Ctrl+C 会尝试向指定电机发送停止命令。若机械臂接近端点、
出现卡滞或方向不符，立即切断电机电源，再检查机构。没有限位开关时，
软件小步限制不能代替硬件限位。

物料相机预览仍保持独立，可在另一个终端运行：

```bash
python3 -B main.py --vision-debug --vision-mode combined
```

默认视觉调试进程不会占用 STM32 串口；机械臂点动使用另一终端的短命令。

## 协议与验证边界

Pi → F4 使用原 `AA 55` 帧：`ARM_JOG=0x20`，payload 为
`id:u8, direction:u8(0=+,1=-), pulses:u16LE`；`ARM_STOP=0x21`、
`ARM_STATUS_REQ=0x22` 的 payload 均为 `id:u8`。ACK/NACK 沿用 `0x90/0x91`，
返回的第二字节为电机 ID。F4 发 `ARM_STATUS=0xA0`、`ARM_DONE=0xA1`，包含
请求序号、ID、结果与原始编码器计数。F4 仅在底盘空闲时接受点动，超时或
编码器失败时尝试停止该轴并上报失败。
发生超时、编码器或停机命令失败后，F4 锁住后续点动；检查机械臂和供电后重启 F4，
不要直接重复发步进命令。

到位判据暂按 F4 工程现有的 3200 脉冲/圈、65536 编码器计数/圈计算；
须在现场核对 5/6/7 号驱动器细分设置和真实位移。成功回包代表编码器变化
达到暂定阈值，不证明方向、行程、限位或摄像头画面已达到目标。

本机自动测试只验证 Pi 编解码和请求状态机；F4 仍需目标编译、烧录及现场
逐轴低速试验。本机修改不会自动出现在树莓派 `/home/pi/文档/pi`。
