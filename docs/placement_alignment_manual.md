# 松爪前对准与一次性放置接入说明

## 安全规则

`PlacementAlignmentController` 强制执行：

```text
VISION_LOCATE_START 一次 → 等回复
→ 发送物料圆心 (x, y)，直到画面中心坐标系下为 (0, 0)
→ 停止发送坐标 → VISION_LOCATE_STOP
→ 下降 → 松爪一次 → 撤离
```

画面坐标以中心为 `(0, 0)`，x 向右为正，y 向下为正，单位是整数像素。下位机根据坐标流
自动调整底盘。坐标帧不等待回复。`(0, 0)` 只来自实测圆心四舍五入后的结果，目标丢失
不会被写成原点。

平面位置锁定后 `needs_observation` 永远为假；即使上层继续传图，任务协调器也会丢弃，
也不会再发圆心坐标。松爪命令发出后不允许重发，也不会重新识别、调整或二次摆放。
开始指令无回复、坐标发送失败、停止指令失败、下降/松爪/撤离失败或总超时，都会在松爪前
保持夹持并进入故障。已经进入视觉定位时，故障路径会再发一次停止指令。

## 标定

定位不再使用像素到毫米矩阵，也不再由上位机分别驱动横移和伸缩。`vision_calibration.camera`
仍可保存相机内参、畸变系数和目标平面单应矩阵。完成棋盘格/平面标定并用已知尺寸复核后，
才同时设置 `calibrated=true`、`apply=true`；默认恒等矩阵且 `apply=false`，不会伪装成已完成
去畸变或平面映射。

## 机构接口

真实接口需继承/实现 `FeedbackMechanism` 的：

- `start(action, value)`：只启动下降、松爪或撤离中的一个动作。
- `poll(action)`：根据下位机动作完成事件返回 `BUSY/SUCCEEDED/FAILED`。

现有 `TimedMechanism` 只有固定时间，占位属性 `feedback_capable=false`，禁止用于正式
自动放置。仓库里尚无下降、松爪、撤离的 STM32 协议，所以接入前调用
`FeedbackMechanism` 会明确报错，不会盲动。视觉定位本身走 `0x30/0x31/0x32`。

## 定位目标

`resolve_placement_target()` 取当前任务颜色在画面中唯一、稳定的物料最小外接圆圆心。
环心不参与这条坐标流。任务生成时，第二批码垛步骤仍记录第一批同色物料的环位。

已有物料的识别发生在下一件松爪之前，因此不构成对上一件已完成放置的复查或返工。

## 推荐验证记录

1. 离线照片：四颜色、空环、持物遮挡、不同偏心。
2. 静止实时画面：记录稳定帧、误检率和环心抖动。
3. EN 禁止或安全台架：确认只发出一次开始指令，坐标符号与画面一致，`(0, 0)` 后发出停止指令。
4. 赛前重复试验：记录最终偏心、标准差、最坏值、松爪位移和两层码垛成功率。
5. 完整流程：确认条件不满足不松爪；每个放置步骤 RELEASE 只出现一次，之后只有
   RETREAT。
