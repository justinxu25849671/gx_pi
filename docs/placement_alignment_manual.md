# 松爪前对准与一次性放置接入说明

## 安全规则

`PlacementAlignmentController` 强制执行：

```text
稳定目标 → 横移（如需要）→ 等完成反馈 → 重新识别
         → 伸缩（如需要）→ 等完成反馈 → 重新识别
         → 连续满足容差 → 锁定平面位置 → 下降 → 松爪一次 → 撤离
```

平面位置锁定后 `needs_observation` 永远为假；即使上层继续传图，任务协调器也会丢弃。
松爪命令发出后不允许重发，也不会重新识别、调整或二次摆放。任何目标丢失、质量不足、
动作失败、修正次数超限或总超时都会在松爪前保持夹持并进入故障。

## 标定

`vision_calibration.poses` 分别保存取料、第一层放置和第二层码垛姿态。每项包括固定
观察高度、旋转角、落点参考像素和 2×2 像素误差到动作毫米量的矩阵：

```text
[横移 mm] = [a b] [图像 dx]
[伸缩 mm]   [c d] [图像 dy]
```

矩阵允许交叉项，不能默认图像横轴就是车辆左右、纵轴就是机械臂前后。用小幅单轴动作
测量图像变化，拟合矩阵后再验证修正方向确实让误差减小。还需分别测量升降横漂、夹持
偏心和松爪位移，用结果确定对准容差。当前三个姿态均为 `calibrated: false`，零矩阵
绝不能直接改成已标定。

`vision_calibration.camera` 另存相机内参、畸变系数和目标平面单应矩阵。完成棋盘格/
平面标定并用已知尺寸复核后，才同时设置 `calibrated=true`、`apply=true`；默认恒等矩阵
且 `apply=false`，不会伪装成已完成去畸变或平面映射。

## 机构接口

真实接口需继承/实现 `FeedbackMechanism` 的：

- `start(action, value)`：只启动一个动作；横移和伸缩的 `value` 单位为标定后的毫米。
- `poll(action)`：根据下位机动作完成事件返回 `BUSY/SUCCEEDED/FAILED`。

现有 `TimedMechanism` 只有固定时间，占位属性 `feedback_capable=false`，禁止用于正式
自动放置。仓库里尚无横移、伸缩、下降、松爪、撤离的 STM32 协议，所以接入前调用
`FeedbackMechanism` 会明确报错，不会盲动。

## 第一层与第二层

- 第一层：`resolve_placement_target()` 取任务对应的稳定环心。
- 第二层：只取当前画面中唯一、稳定的第一层同色物料参考点；任务生成时码垛环位也
  改为第一批同色物料的位置，不再沿用第二批粗加工环位。

已有物料的识别发生在下一件松爪之前，因此不构成对上一件已完成放置的复查或返工。

## 推荐验证记录

1. 离线照片：四颜色、空环、持物遮挡、不同偏心。
2. 静止实时画面：记录稳定帧、误检率和环心抖动。
3. EN 禁止或安全台架：逐个验证横移/伸缩符号和完成反馈。
4. 赛前重复试验：记录最终偏心、标准差、最坏值、松爪位移和两层码垛成功率。
5. 完整流程：确认条件不满足不松爪；每个放置步骤 RELEASE 只出现一次，之后只有
   RETREAT。
